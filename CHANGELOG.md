# Changelog

Notable changes to OpenSharing are recorded here and in
[GitHub Releases](https://github.com/OpenSharing-IO/OpenSharing/releases).

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Versioning is described in [RELEASE.md](./RELEASE.md).

When a release fixes a publicly known runtime vulnerability that already had a
CVE (or equivalent) at release time, that CVE is listed under **Security**.
