# Code of Conduct

OpenSharing follows the LF Projects Code of Conduct.

As stated in the project's [Technical Charter](./GOVERNANCE.md) (§4.b), in the
absence of a project-specific code of conduct the
[LF Projects Code of Conduct](https://lfprojects.org/policies/code-of-conduct/)
applies to all participants in the project.

## Reporting

To report a violation of the Code of Conduct, contact **conduct@lfai.foundation**.
Reports are handled confidentially.
