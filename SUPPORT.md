# Support

Need help with OpenSharing? Here's where to go.

## Documentation

- The protocol specifications live in [`spec/`](./spec/).
- The [README](./README.md) covers concepts, the asset model, and connectors.
- Project website: https://opensharing.io

## Questions and discussion

- **Questions and proposals** — open a
  [GitHub Issue](https://github.com/OpenSharing-IO/OpenSharing/issues).
- **Bugs in a connector or the spec** — open a GitHub Issue with steps to
  reproduce.
